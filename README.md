# 🚗 Listo

**Listo** is a backend service for a peer-to-peer car rental platform, enabling users to rent vehicles directly from other users.  
It’s built with **Python** and orchestrated using **Docker Compose** for easy setup and deployment.

---

## 🛠️ Installation & Setup

To get started with Listo locally:

```bash
git clone https://github.com/FrMnJ/Listo.git
cd Listo
docker compose up -d
```

Once running, the backend services will be available and ready for development or testing.
